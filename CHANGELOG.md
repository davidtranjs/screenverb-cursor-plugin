# Changelog

All notable changes to this plugin will be documented here.

## 1.1.0 - initial release

- Added the `screenverb` MCP server pointing at ScreenVerb's hosted Streamable HTTP endpoint (`https://mcp.screenverb.com/mcp`).
- Auth uses OAuth with ScreenVerb sign-in. No API key or client ID to configure.
- Version matches the server version in the official MCP Registry (`com.screenverb/screenverb`).
